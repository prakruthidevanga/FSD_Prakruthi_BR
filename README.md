# 🌐 Full-Stack Web Development Practical Labs

A structured collection of hands-on frontend web development laboratory exercises, responsive UI components, DOM manipulation scripts, and JavaScript fundamentals developed during coursework at Alliance University.

---

## 📌 Repository Overview

This repository demonstrates foundational web development principles:
- **Semantic HTML5 & Modern CSS3:** Grid and Flexbox layouts, responsive forms, college timetable tables, and typography.
- **Modern JavaScript (ES6+):** Arrow functions, higher-order functions (`map`, `filter`, `reduce`), scope/closures, and dynamic DOM manipulation.
- **Interactive UI Mini-Apps:** Client-side calculators, dynamic registration and login forms with real-time validation.

---

## 📂 Key Implementations

- `Alliance_Login_Form.html` & `Registration_Form.html` — Accessible, styled forms with client-side field validation.
- `Calculators.html` — Interactive JavaScript calculator with event listeners and arithmetic state tracking.
- `Arrow_Functions.html` & `Basics and Variables in js.html` — Core ES6 syntax demonstrations.
- `College_Time_Table.html` & `Resturant_Menu.html` — Responsive tabular and catalog layouts.

---

## ⚙️ How to View & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/prakruthidevanga/FSD_Prakruthi_BR.git
   cd FSD_Prakruthi_BR
   ```
2. Open any `.html` file directly in your browser or run a live server:
   ```bash
   npx serve .
   ```
